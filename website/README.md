# English Doctor — website

Static landing page for the English Doctor domain (IELTS, Spoken English, Vocabsolution).
Colours come from the logo: royal blue `#0b45c9`, deep navy `#06277a`, golden yellow `#ffc81f`, white.

No build step. Open `index.html`, or upload the `website/` folder to any static host
(GitHub Pages, Netlify, cPanel `public_html`) and point the domain at it.

## Before going live, replace the placeholders
- Phone `+880 1XXX-XXXXXX` / `tel:+8801XXXXXXXXX` (index.html) and `WHATSAPP_NUMBER` (main.js)
- Email `info@englishdoctor.com`
- Course prices (sample values)
- Stats in the yellow strip (`data-count`)
- Student reviews — use real reviews with the student's permission
- Facebook / YouTube / Google Play / Privacy Policy links (`href="#"`)
- Mentor photo: add a real photo and swap `assets/logo.png` in the mentor section
