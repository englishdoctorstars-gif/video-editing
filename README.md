নতুন (v0.3.0):
- **স্তর যাচাই পরীক্ষা (Placement Test):** অনবোর্ডিং-এর শেষে ঐচ্ছিক, প্রোফাইল থেকে আবার দেওয়া যায়। বইয়ের বিভিন্ন অধ্যায় থেকে ১০টি প্রশ্ন আসে: ৩টি সহজ, ৩টি মাঝারি, ৪টি কঠিন। কঠিন প্রশ্নে বেশি নম্বর, তাই ভাগ্যক্রমে সহজ প্রশ্ন মিলে গেলেও উঁচু স্তরে ওঠা যায় না। ফলাফল প্রাথমিক, মধ্যম বা উন্নত স্তর এবং কোথা থেকে শুরু করবেন তার পরামর্শ। মধ্যম স্তর পেলে পরীক্ষার মধ্যম সেটগুলো খুলে যায়, উন্নত পেলে সব সেট।
- **হোম-স্ক্রিন উইজেট "আজকের শব্দ":** শব্দ, পদ, অর্থ ও ধ্বনি-সূত্র দেখায়। ট্যাপ করলে সরাসরি সেই শব্দের গল্প খোলে। প্রতিদিন নিজে থেকে নতুন শব্দ আসে।
- **শেয়ার কার্ড:** English Doctor ব্র্যান্ডিংসহ ছবি-কার্ড, ইন্টারনেট ছাড়াই তৈরি হয়। পাওয়া যাবে Memory Hook, Confused Pair, হোমের "আজকের শব্দ" ও রিভিউ কার্ডে।

সব অধ্যায়ে যা আছে:
- বইয়ের **১-৩-৭-৩০ দিনের পুনরাবৃত্তি পদ্ধতি**: শেখা শব্দ ৩য়, ৭ম ও ৩০তম দিনে রিভিউতে আসে। "ভুলে গেছি" চাপলে চক্র আবার ১ম দিন থেকে শুরু হয়।

- ব্রিটিশ উচ্চারণ (ডিভাইসের TTS দিয়ে)।

## বিল্ড

প্রয়োজন: JDK 17+ ও Android SDK (platform 35)।

```bash
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest    # SRS, পরীক্ষার নিয়ম, কন্টেন্ট যাচাই, স্ক্রিনশট
./gradlew :app:recordPaparazziDebug # app/src/test/snapshots/images-এ স্ক্রিনশট
```

প্রতিটি পুশে GitHub Actions ইনস্টলযোগ্য debug APK তৈরি করে। এটি পাওয়া যাবে Actions → Android build → `vocabsolution-debug-apk`-এ।

## কন্টেন্ট পুনরায় তৈরি (বই আপডেট হলে)

```bash
pip install pymupdf
python3 -I tools/extract/clean_text.py BOOK.pdf clean.txt
python3 -I tools/extract/parse_book.py clean.txt app/src/main/assets/content BOOK.pdf
```

অধ্যায় ১০-এর টেবিলে একটি সেল কয়েক লাইনে ভাঙা থাকে। তাই `tables.py` টেবিলের হেডার-ব্যান্ড ও সারির রেখার অবস্থান থেকে সারি-কলাম পুনর্গঠন করে।
`clean_text.py` PDF-এর লেখা থেকে বাংলা যুক্তাক্ষরের সমস্যাগুলো ঠিক করে: ডুপ্লিকেট কার-চিহ্ন এবং লাইনের মাঝে ভাঙা শব্দ। `parse_book.py` প্রতিটি সেটের সংখ্যা বইয়ের ঘোষিত সংখ্যার সাথে মিলিয়ে দেখে। একই যাচাই `ContentValidationTest`-এও চলে।
